# Reference pronunciations (optional)

By default the **Listen to Pronunciation** button uses the browser's built-in English
text-to-speech, so nothing is needed here.

To use your own recordings, drop one file per word in this folder; the game tries the file
first and only falls back to text-to-speech if it is missing:

    book.mp3  chair.mp3  cell_phone.mp3  apple.mp3  pen.mp3  pencil.mp3

File names are the `key` of each word in `backend/config.py`.
